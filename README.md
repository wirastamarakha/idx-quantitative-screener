# 📈 Algorithmic IDX30 Volatility Screener

An automated quantitative analysis tool built with Python to extract and analyze market data from the Indonesian Stock Exchange (IDX30). 

As an Actuarial Science student, I built this tool to move beyond manual Excel data gathering. This script automates historical data scraping and calculates the **Annualized Volatility (Risk)** of Indonesia's top 30 blue-chip stocks, allowing for dynamic risk assessment and better position sizing.

### ⚙️ Features
- **Automated Data Extraction:** Scrapes real-time historical market data using Yahoo Finance API.
- **Statistical Risk Analysis:** Calculates daily returns and annualized standard deviation (volatility).
- **Automated Export:** Formats and exports the quantitative findings directly into Excel for further dashboard integration and financial modeling.

### 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** `yfinance`, `pandas`, `numpy`
- **Output:** `.xlsx` (Excel)

### 🚀 How to Run
The core logic is contained in `IDX30_Volatility_Screener.ipynb`. It can be run locally via Jupyter Notebook or through Google Colab without any installation.
